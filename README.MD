## ✨ Features

- 🎨 **Modern Dark UI:** Gorgeous custom dark palette styled with Tailwind-inspired slate colors (`#0f172a`, `#1e293b`).
- 📱 **Fully Responsive:** Designed using modern CSS, ensuring a perfect experience on mobile, tablet, and desktop screen sizes.
- ⚡ **High Performance:** Built using clean, native HTML5 and CSS3—completely free of heavy libraries or unnecessary runtime dependencies.
- 🛠️ **Social Links & Contact:** Built-in interactive cards linking to GitHub and email with smooth hover scale effects.
- 🏷️ **Tech Tag Badges:** Displays key skills using styled tags backed by crisp FontAwesome iconography.

## 🚀 Getting Started

To run this project locally, simply follow these steps:

### Prerequisites
All you need is a modern web browser (e.g., Chrome, Firefox, Safari, Edge).

### Running Locally
1. **Clone the repository:**
   ```bash
   git clone https://github.com/berty0/personalWeb.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd personalWeb
   ```
3. **Open the project:**
   - Double-click `index.html` to open it in your browser.
   - Or, run it with a VS Code extension like **Live Server** for real-time updates while editing.

---

## 🌐 Deployment

This website is automatically deployed and hosted using **GitHub Pages**. To deploy your own custom copy:
1. Fork this repository to your GitHub account.
2. In your fork, go to **Settings** > **Pages**.
3. Under **Build and deployment**, set the source to **Deploy from a branch**.
4. Select `main` (or the root branch) and click **Save**.
5. Your custom portfolio will be online at `https://<your-username>.github.io/personalWeb/`.
